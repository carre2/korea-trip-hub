초안 동작
- 비자·K-ETA, 공항, 교통, SIM, 예산·환전, 음식, 축제, 숙박, 일정 질문을 관련 페이지로 연결한다.
- 답변은 자동 안내임을 알리고 관련 링크 하나를 제공한다. UTM으로 채널·주제를 구분한다.
- 12개 언어를 지원한다. 명시적 언어 설정을 우선하며 자동 언어 추정은 보조다.
- 언어는 여권 국적이 아니다. 국가별 비자 안내는 여권/국적 표현과 국가 하나가 명시된 경우만 선택한다.
- 비자 허가 여부·수수료·처리기간을 자동으로 판단하거나 약속하지 않는다. 사이트 안내와 공식 출처 확인을 권한다.
- 모르는 질문, 단순 감상, 여러 주제가 섞인 질문, 외부 링크, 민감한 개인정보, 환불·긴급 문의는 자동 전송 대상에서 제외한다.
- Threads DM은 구현하지 않았다. 공개 답글과 DM 지원을 같은 것으로 취급하지 않는다.

실제 자동 전송 연결에 남은 것
1. Korea Trip Hub 전용 Meta 앱의 계정 승인과 필요한 댓글/메시지/Threads 권한 확인.
   현재 확인된 기존 앱은 Kira Publisher와 modeu-info-publisher로, 변경하거나 재사용하지 않음.
2. 공식 API로 들어오는 이벤트 검증 및 계정 소유권 확인. Instagram webhook 서명 검증 필수.
3. 영속 저장소에서 이벤트당 1회 처리, 같은 사람·같은 주제의 재답변 제한, 자기 답글 무시, 즉시 중지 설정.
4. Instagram 메시지의 현재 정책상 허용된 응답 범위 확인. 댓글만으로 먼저 DM을 보내지 않음.
5. Threads는 자기 계정 글에 들어온 새 답글에 한정. 불특정 글 검색 후 자동 홍보 금지.
6. 토큰은 서버 비밀 저장소에만 보관. 공개 소스·브라우저·채팅·운영 문서에 기록하지 않음.
7. 테스트 계정에서 수신 → 관련 링크 답변 → 중복 차단 → 중지까지 검증 후 운영 상태로 변경.
8. Meta 기본 환영 답장과 별도 서버 답장이 같은 첫 DM에 중복되지 않게 하나의 처리 경로만 사용.
