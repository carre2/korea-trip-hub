## 기준 현실 (실측)
- **평균 참여 시간 37초** (낮음) — 짧게 보고 이탈.
- 상위 유입 페이지 = **번체/인니/베트남 비자 페이지** (TW·HK·ID·VN). 채널 = Cross-network + Organic.
- 전략 방향: "비자로 들어와 짧게 보고 이탈" → **깊은 탐색 · 수익 전환**으로.

## 이미 완료 (2026-11-03 세션)
- ✅ NextSteps 클릭 추적 복구 (`transport_type:'beacon'`) — 퍼널 측정 가능해짐.

## 추천 실행 순서
1. **P0 ②** (제휴 그리드) — 유일한 직접 매출, 비자 트래픽에 즉시 부착. 카피 완성형 → 제휴링크만 확보되면 1~2일.
2. **P0 ①** (히어로 정돈)로 ②의 노출 극대화.
3. **P1(③④⑤)**로 37초 체류 끌어올리기 → P2·P3는 데이터 보며 순차.

## 진행 전 결정 필요한 의존성
- **제휴 계정**: eSIM(Airalo/Nomad 등)·WOWPASS·AREX의 affiliate 가입 상태? (Klook/KKday는 기존 트래킹 재사용 가능)
- **환율 API**: 무료 티어(ExchangeRate-API 등) 키 발급 여부
- **지도(⑥)**: 비용·복잡도 커서 P2 후반 권장

## 전역 제약 (모든 작업 공통)
- **facts-harness**: 가격·할인·시간 등 변동 수치는 검증된 fact(`data/facts.json`, 출처+검증일+확인링크)만. 미검증 수치 금지.
- **photo-policy**: 실제 CC 사진만, 실존 명소 AI 위조 금지.
- **가짜 후기/제휴 위장 금지**.
- **정적배포**(output:export): 외부 API는 클라이언트 fetch + 캐시 + 실패 폴백.
- **prebuild 게이트**: 데이터 변경 시 `npm run build` 전체 통과 후 push (게이트 실패=무음 배포차단).
