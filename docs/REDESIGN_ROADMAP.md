## ⑫ 계정·동기화·개인화 (2026-11-03 결정 · GA4 측정 후 착수)
**결정:** "관심사 자동 전송"은 **온사이트 개인화**(이메일 발송 아님). **GA4 측정(2026-11-06) 이후 Phase 1부터** 착수.

- **핵심 원칙:** 로그인은 **절대 게이트 아님** — 모든 도구는 지금처럼 비로그인 그대로, 로그인은 "동기화 + 개인화" 덤(선택적 업그레이드).
- **토대:** Cloudflare Worker(`worker/index.js`)에 이미 백엔드 존재(`/api/chat`) → auth 콜백 + 사용자 저장(Cloudflare KV/D1) 추가 가능. Next는 `output:export` 정적이라 **서버 로직은 Worker 쪽**에 둔다.
- **제공자 우선순위(실제 시장 기준):** Google(범용) + LINE(TW·TH·JP) + Facebook(ID·VN·PH) + Apple. ★카카오는 한국용이라 후순위(상위 트래픽은 ID·TW·VN·HK).
- **Phase 1 (먼저):** 선택적 로그인 → **My Trip·저장장소·체크리스트를 user별 KV/D1에 동기화**(현재 localStorage=기기별 → 로그인 시 크로스기기). 로그인 시 localStorage ↔ 서버 머지 로직 필요.
- **Phase 2:** 관심사 기반 **온사이트 개인화 추천**.
- **보류:** 이메일 다이제스트 — 하려면 **명시적 옵트인 동의** 필수(메모리 [[sns-auto-post-ban]] 교훈).
- **주의:** 개인정보 저장 → **개인정보처리방침 갱신** 필요. 비로그인 UX 무손상 유지. OAuth는 PKCE·세션 쿠키 보안.

## 전역 제약 (모든 작업 공통)
- **facts-harness**: 가격·할인·시간 등 변동 수치는 검증된 fact(`data/facts.json`, 출처+검증일+확인링크)만. 미검증 수치 금지.
- **photo-policy**: 실제 CC 사진만, 실존 명소 AI 위조 금지.
- **가짜 후기/제휴 위장 금지**.
- **정적배포**(output:export): 외부 API는 클라이언트 fetch + 캐시 + 실패 폴백.
- **prebuild 게이트**: 데이터 변경 시 `npm run build` 전체 통과 후 push (게이트 실패=무음 배포차단).
